FiveM and PC tips

Quick fixes that stop most shader, crash, and FPS problems before you reinstall everything.

Before you install anything

  • Close FiveM and GTA V completely.
  • Have at least 20 GB free on the drive that holds FiveM and GTA V.
  • Install GTA V through Steam, Epic, or Rockstar. FiveM needs a real copy.

Do not mix these files

  • FiveM plugins\d3d11.dll stays in FiveM.
  • ENB d3d11.dll stays next to GTA5.exe.
  • Mods (.rpf) go in FiveM mods, never into the GTA V folder.

ReShade and ENB keys

  • FiveM ReShade: Home
  • ENB overlay in single player: Shift + Enter or End
  • If Home does nothing, another overlay stole the key. Turn Discord overlay off and try again.

Crashes after shaders

  • Update GPU drivers, then reboot.
  • Clear FiveM cache.
  • Turn off Discord overlay, NVIDIA overlay, and Xbox Game Bar.
  • Some servers block graphics mods. That is a server rule, not a broken pack.

More FPS

  • Windows power plan: High performance or Ultimate performance.
  • Play on an SSD, not a spinning hard drive.
  • In NVIDIA / AMD, set FiveM to High performance / Gaming.
  • Close Chrome tabs, recording software, and RGB apps while you play.
  • ReShade depth and heavy effects cost FPS. Turn down what you do not need.

Windows settings that help

  • Game Mode on. Xbox Game Bar off if it causes crashes.
  • Hardware-accelerated GPU scheduling: try On, reboot, test. If it is worse, turn it Off.
  • Fullscreen optimizations: right-click FiveM.exe → Properties → Compatibility → disable fullscreen optimizations if alt-tab is messy.

GTA V / Rockstar

  • Open the Rockstar launcher once so it is logged in before FiveM.
  • If FiveM says the game files are invalid, verify / update GTA V in Steam or Rockstar.
  • Do not put ENB files inside FiveM. They will not load there.

Still stuck?

  • Re-read the install guide and check the two destinations.
  • Ask in GLOW UP RP Discord. Join the server with this FiveM link.
  • A screenshot of FiveM.app\plugins and your GTA V folder helps staff help you faster.
