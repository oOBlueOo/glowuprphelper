Update your graphics drivers

Old drivers are a top reason ReShade, ENB, and FiveM crash or look broken. Use the official app for your GPU.

STEP 1

Find your GPU

  1. Press Windows + R.
  2. Type dxdiag and press Enter.
  3. Open the Display tab.
  4. Read the Name line. That tells you NVIDIA, AMD, or Intel.
dxdiag
STEP 2

Download from the official site

Pick your brand. Do not use random “driver booster” websites.

NVIDIA App AMD Adrenalin Intel drivers
  • NVIDIA: install NVIDIA App, open Drivers, download Game Ready.
  • AMD: install Adrenalin, check for driver updates.
  • Intel: use Intel Driver & Support Assistant or the Arc/Iris page.
STEP 3

Install, reboot, then test FiveM

  1. Close FiveM, Discord overlays, and your browser if the installer asks.
  2. Install the driver. If you see a Custom / Clean install option, use it.
  3. Restart the PC.
  4. Open FiveM and join once. If things look off, clear your cache.

Windows Update can install older GPU drivers later. If FiveM breaks after a Windows update, install the official Game Ready / Adrenalin driver again.

Laptop users

  • Many laptops have two GPUs. FiveM should use the high-performance one.
  • Windows Settings → System → Display → Graphics → add FiveM.exe → change to High performance.
  • Plug in the charger. Many laptops cut GPU power on battery.

If the install fails

  • Run the official installer as administrator.
  • Turn off overlay apps first: Discord, NVIDIA, Xbox Game Bar.
  • Do not use third-party driver packs or cracked “tweaked” drivers.
