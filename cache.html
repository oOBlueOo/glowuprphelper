Clear your FiveM cache

Do this after installing shaders, if textures look old, or if a server will not finish loading.

Clear cache for me Open cache folder

Open cache folder opens File Explorer on FiveM.app\data. The clear-cache helper closes FiveM, then deletes only cache, server-cache, and server-cache-priv. It does not touch game-storage, GTA V, or your shader files. Windows may show SmartScreen — Run anyway is fine.

Delete these

  • cache
  • server-cache
  • server-cache-priv

Leave these alone

  • game-storage — settings and local data
  • Your GTA V game folder
  • The Glow mods and plugins you just installed
STEP 1

Close FiveM, then open the data folder

  1. Fully close FiveM. Check Task Manager if it is still running.
  2. Press Windows + R.
  3. Paste the path below and press Enter.
%localappdata%\FiveM\FiveM.app\data Open this folder for me
STEP 2

Delete the three cache folders

  1. Inside data, select cache, server-cache, and server-cache-priv.
  2. Delete them. FiveM will rebuild them the next time you join.
  3. Do not delete game-storage.

The first join after this is slower. That is normal. The server is sending files again.

STEP 3

Start FiveM again

  1. Launch FiveM.
  2. Join GLOW UP RP once and let it finish downloading.
  3. If ReShade does not appear, press Home and load the Glow preset.

Clearing cache does not remove the shader pack. Your mods and plugins stay where you put them.
