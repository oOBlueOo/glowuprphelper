How to install

This pack has two destinations. Plugins and mods go into FiveM AppData. ENB files go into your GTA V game folder.

Get the pack The 3 folders FiveM install GTA V ENB

What is inside the pack

Extract Glow_shaders.rar to your Desktop. You should see these three folders. Each one goes to a different place.

plugins

ReShade, QuantV, and shader files. Drop these into FiveM.

mods

The .rpf visual files. Drop these into FiveM.

GTA 5

ENB files. Drop these into your real GTA V folder. Not FiveM.

STEP 1

Extract the pack

  1. Close FiveM and GTA V first.
  2. Right-click Glow_shaders.rar and extract it.
  3. Open the extracted folder. You should see GTA 5, mods, and plugins.
STEP 2

Open FiveM AppData

  1. Press Windows + R.
  2. Paste the path below and press Enter.
  3. This opens FiveM.app. That is the folder you want.
%localappdata%\FiveM\FiveM.app Open FiveM folder for me

Click the button, then Run the helper. File Explorer opens on your real FiveM.app folder — not a Run box.

STEP 3

Find mods and plugins

Inside FiveM.app you will already see two folders:

  • mods
  • plugins
Open mods folder Open plugins folder

Those are the only two FiveM folders you need. Do not drop the ENB files here.

STEP 4

Drop the mods in

  1. Open the pack folder named mods.
  2. Select the .rpf files:
    nopixel.rpf
    nopixel-desert-grass.rpf
    nopixel-light-addons.rpf
  3. Drag them into FiveM.app\mods.
  4. If Windows asks to replace files, click Replace.
Open the mods folder for me
STEP 5

Drop the plugins in

  1. Open the pack folder named plugins.
  2. Select everything inside it, including reshade-shaders, QuantV.asi, d3d11.dll, and the ReShade ini files.
  3. Drag all of that into FiveM.app\plugins.
  4. Replace files if asked.
Open the plugins folder for me

Copy the files inside plugins, not the whole FiveM.app folder.

STEP 6

Drop ENB files into GTA V

  1. Open your GTA V install folder. Common path:
C:\Program Files\Rockstar Games\Grand Theft Auto V Open GTA V folder for me

This finds your real install and opens File Explorer with GTA5.exe selected.

  1. Open the pack folder named GTA 5.
  2. Select everything in there: enbseries, d3d11.dll, enbseries.ini, and the .fx files.
  3. Drop those files next to GTA5.exe.
  4. Replace files if asked.

These ENB files go in the real GTA V game folder. They do not go in FiveM AppData.

After install

  • Start FiveM and join a server.
  • Press Home to open ReShade.
  • Load the Glow / Colorwave preset if it does not auto-load.
  • In single player, ENB is usually Shift + Enter or End.

If it looks wrong

  • Make sure mods went to FiveM mods, not GTA V.
  • Make sure ENB went next to GTA5.exe, not into FiveM.
  • Do not mix the two d3d11.dll files. One is for FiveM plugins, one is for GTA V ENB.
  • Some FiveM servers block graphics mods.
